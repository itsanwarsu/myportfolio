Ecommerce-App

Custom-designed full-stack e-commerce application built with React, Express.js, Node.js, PostgreSQL, and MongoDB, focused on performance, scalability, and modern security standards. The application integrates JWT authentication/authorization with Role-Based Access Control (User & Admin). Zustand is used for structured frontend state management, synchronizing cart data, product catalogs, and user sessions. The platform also features real-time chat powered by Socket.IO, with MongoDB dedicated to storing conversations and messages, while PostgreSQL manages structured data such as users, products, orders, and transactions.

Main Tech Stack

Frontend: React.js, Zustand (State Management), Axios, Tailwind CSS Backend: Node.js, Express.js Database: MongoDB & PostgreSQL Security & Auth: JWT (JSON Web Token), Bcrypt, Helmet, CORS, Express Rate Limit
